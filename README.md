# DSA in C++

This repository contains my daily practice of Data Structures and Algorithms using C++.

The goal is to build consistency in problem solving while learning how to use Git and GitHub through regular commits and updates.

## Topics

- Arrays
- Strings
- Linked Lists
- Stacks and Queues
- Recursion
- Searching and Sorting
- Hashing
- Trees
- Graphs
- Dynamic Programming
- Greedy Algorithms
- Bit Manipulation

## Structure

Problems are organized by topic. Each solution includes the problem statement or source, approach, time complexity, space complexity, and C++ implementation where applicable.

## Progress

I will solve and push problems regularly to track my learning journey and improve my understanding of DSA and GitHub.
